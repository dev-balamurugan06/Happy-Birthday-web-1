# 🎂 Happy Birthday Nandhu

A beautiful and interactive birthday website specially created for **Nandhu** ❤️.

This website is designed as a digital birthday gift filled with memories, heartfelt messages, love notes, countdowns, and a fun cake-cutting celebration experience.

---

## ✨ Features

- 🎉 Elegant Birthday Landing Page
- ⏳ Live Birthday Countdown
- 📸 Memories Gallery
- 💖 100 Special Reasons
- 💌 Interactive Birthday Letter
- 🎂 Animated Cake Cutting Experience
- 🎊 Confetti Celebration Effect
- ✨ Glassmorphism Design
- 📱 Fully Responsive Design

## ⏰ Countdown Setup

```javascript
const birthdayDate = new Date('2026-06-04T00:00:00+05:30').getTime();
```
